Вместе с WebSocket идут: CVD (Cumulative Volume Delta — дивергенции покупателей/продавцов для раннего выхода), OBI (Order Book Imbalance L5 — дисбаланс стакана для подтверждения входа, порог |OBI| > 0.4), Tape Speed (скорость агрессивных ордеров в секунду — фильтр боковика, порог > 5 сделок/сек), VWAP multi-TF (дневной VWAP как динамическая поддержка/сопротивление, откат к VWAP = точка входа). Источник: исследование Kimi + Perplexity 2026-03-07.
- [2026-03-07] [2026-03-07] Батники Windows: 1) старт бота, 2) стоп + убить все процессы, 3) чистка кэша, 4) сбор логов в архив. Добавить в Фазе 1.2 перед первым тестовым запуском.
- [2026-03-07] [2026-03-07] Cursor Automations (автономный агент по расписанию) — после Фазы 1.3 когда есть логи и статистика. Идея: агент запускается автоматически после каждой сессии бота, читает logs/, считает WR/PnL/avg hold time и пишет дайджест. Возможные сценарии: 1) ежедневный анализ логов → summary в Slack/Telegram, 2) поиск аномалий (ghost positions, SL ниже порога, перетрейдинг), 3) авто-обновление PLAN.md с реальной статистикой. Требует: рабочий бот с логами + настройка Cursor Automations + MCP для доступа к репо.
