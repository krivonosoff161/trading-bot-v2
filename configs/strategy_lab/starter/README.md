# Strategy Lab starter pack

This directory contains the first always-on local research pack.

The specs are intentionally small enough for a desktop loop:

- `l1_majors_regime_v0` - majors / regime baselines.
- `l2_alts_meme_volatility_v0` - volatile alts and meme-like assets.
- `l2_alts_regime_down_v0` - down/sideways regime checks for fades and retests.
- `l5_ai_equity_proxy_v0` - AI / equity proxy symbols.

These specs are public methodology only. Exact private result tables, candidate
registry rows, and parameter findings belong in `trading-bot-research`.
