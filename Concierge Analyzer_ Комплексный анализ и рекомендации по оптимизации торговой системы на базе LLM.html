Executive Summary

Система Concierge Analyzer демонстрирует фундаментальное противоречие между архитектурой торговой стратегии и реальными ограничениями оператора. Анализ одного дня торговли выявил критические узкие места и указал на оптимальный путь развития.

Критические проблемы

  • • 251% от положительного результата потеряно на unattended-позициях
  • • Фрагментированный UX с ручными переключениями контекста
  • • Отсутствие автоматической инвалидации сценариев
  • • Несоответствие временных горизонтов LLM и оператора

Ключевые решения

  • • Фокус на range trading в вечернем окне
  • • Автоматизация исполнения через OKX API
  • • Динамическая защита через Chandelier Exit
  • • Периодический LLM-рескоринг каждые 4 часа

Ключевой инсайт

Лучшая сделка дня — XRP LONG +92.70 USDT за 3 минуты — была выполнена вне системной логики аналитика, являясь ручным range trade. Это указывает на принципиально иной путь развития: фокус на краткосрочные сетапы с полным контролем в рамках вечернего окна.

Архитектура SL/TP для выживания без присмотра

Три уровня защиты: концепция "луковицы"

Ядро — начальный SL

Для range:

За пределами боковика + 0.5×ATR(4H) буфер

Для trend:

За swing low/high на 4H + 1×ATR(4H)

Средний слой — break-even

Триггер:

Прибыль достигает +1.5×ATR(1H)

Действие:

SL на уровень входа + 0.15% буфер

Внешний слой — трейлинг

Активация:

Движение цены на +2.5×ATR

Шаг:

0.5×ATR при новом экстремуме

Спецификация Chandelier Exit для крипто

Формула расчета

Для long позиций:
Chandelier Exit = Highest High(22) − ATR(22) × 3.5
Где 3.5 — крипто-адаптивный мультипликатор (стандарт 3.0)

Логика обновления

  • Пересчет при закрытии каждой часовой свечи
  • Округление до значимых уровней для ликвидности
  • Обновление через OKX API без постоянного подключения

Параметры крипто-адаптации

Lookback: 22 часовые свечи (~сутки)
Мультипликатор: 3.5 (диапазон 3.0-4.0)
Обновление: При закрытии 1H-свечи
Округление: До значимых уровней

Условия принудительного выхода (инвалидация)

Структурная

Триггер:

Закрытие 1H-свечи против тренда за 2×ATR от входа

Действие:

Немедленный выход по рынку

Временная

Триггер:

24 часа (range) или 72 часа (trend), прибыль < 0.5×ATR

Действие:

Принудительное закрытие

Индикаторная

Триггер:

ADX(4H) падает ниже 20 при открытой позиции

Действие:

Выход или агрессивный трейлинг

Реконфигурация роли LLM в пайплайне

Максимальная ценность: интерпретация режима рынка

Что делает LLM

  • Классификация режима рынка (trend/range/transition)
  • Оценка "чистоты" сетапа и степени соответствия модели
  • Выявление скрытых рисков, не формализованных в индикаторах
  • Генерация "сценария развития" — ожидаемой последовательности событий

Что делает код (100% детерминированно)

  • Расчёт всех индикаторов по формулам с точностью до цента
  • Проверка жёстких фильтров входа (пороги, условия)
  • Размещение и управление ордерами через API
  • Обновление трейлинг-стопов по расписанию
  • Инициация принудительного выхода по инвалидации

Критическое правило

LLM не генерирует числовые уровни SL/TP напрямую. Конкретные параметры рассчитываются кодом на основе рекомендации LLM (тип стратегии, уровень confidence) и текущих рыночных данных.

Детерминированные vs. генеративные компоненты

Функция Реализация Обоснование

Проверка фильтров входа Код 100% Бинарные решения, нет интерпретации

Конкретные параметры для немедленной имплементации

Модифицированный свинг-фильтр

ADX(4H) > 25
AND ADX(1H) > 20
AND +DI > −DI на обоих ТФ
AND относительный объём > 1.5 × 20-периодный SMA
AND RSI(1H) между 40 и 70
Вход: откат к EMA20(15m) при RSI(15m) < 50

Range-фильтр (приоритетный)

BandWidth(4H) < 12% стабильно 5+ свечей
AND минимум 3 чётких касания верхней и нижней границы
AND RSI(1H) колеблется 30-70 без экстремумов
Вход: лимитный ордер у границы + Stochastic(5m) подтверждение разворота

Параметры защиты

Начальный SL: Структурный уровень + 0.5×ATR(4H)
Break-even: Автоматический при +1.5×ATR(1H)
