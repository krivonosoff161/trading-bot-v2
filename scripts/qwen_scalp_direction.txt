## КОНТЕКСТ СИСТЕМЫ

Торговый анализатор на Python. Три стиля сигналов:
- SWING: 4H + 1H тренд выровнены (ADX ≥ 25 на обоих)
- PULLBACK: 4H тренд есть, 1H в коррекции
- SCALP: 1H ADX ≥ 20 + volume_ratio ≥ 2.0 + пара из whitelist (XRP, ETH)

Направление (_side = "buy" / "sell") определяется так:
```python
_side = (
    _act.get("side")                          # старый движок (5m breakout)
    or ("buy"  if _h1.get("bull") else None)  # 1H бычий тренд
    or ("sell" if _h1.get("bear") else None)  # 1H медвежий тренд
)
```

Это работает для SWING/PULLBACK (они требуют 1H тренд).
Для SCALP это ломается: SCALP специально срабатывает когда 1H = NEUTRAL.

## ВАРИАНТЫ РЕШЕНИЯ (наши идеи)

**Вариант 1 — Простой: брать сторону из supertrend_15m для SCALP**
```python
if _trade_style == "SCALP" and _side is None:
    if _supertrend_dir == "up":
        _side = "buy"
    elif _supertrend_dir == "down":
        _side = "sell"
```
Плюсы: просто, быстро, supertrend — нормальный индикатор
Минусы: supertrend может быть нейтральным / "up" при слабом моменте

**Вариант 2 — С дополнительными условиями**
```python
if _trade_style == "SCALP" and _side is None:
    if _supertrend_dir == "up" and _close > _vwap and _rsi_15m < 70:
        _side = "buy"
    elif _supertrend_dir == "down" and _close < _vwap and _rsi_15m > 30:
        _side = "sell"
    else:
        _trade_style = "NO_TRADE"  # нет ясного направления → отмена
```
Плюсы: фильтрует ложные сигналы, согласован с VWAP
Минусы: может заблокировать сигнал даже при хорошем объёме

**Вариант 3 — Через DI на 1H**
```python
if _trade_style == "SCALP" and _side is None:
    if _plus_di_1h > _minus_di_1h and _supertrend_dir == "up":
        _side = "buy"
    elif _minus_di_1h > _plus_di_1h and _supertrend_dir == "down":
        _side = "sell"
    else:
        _trade_style = "NO_TRADE"
```
Плюсы: DI показывает давление покупателей/продавцов даже в NEUTRAL
Минусы: требует согласования DI + supertrend
