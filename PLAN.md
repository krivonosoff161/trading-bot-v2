# PLAN — Trading Bot V2

## Текущий этап: ЭТАП 1 — Рабочий бот

**Цель:** Стабильный плюс на демо 4 недели подряд.
**Критерий перехода к Этапу 2:** +10-15%/месяц, просадка < 5%.

---

## Фазы Этапа 1

### Фаза 1.1 — Фундамент (сейчас)
- [ ] Структура проекта
- [ ] Система логирования (ПЕРВЫМ — всё остальное строится поверх)
- [ ] OKX клиент (WebSocket + REST)
- [ ] Базовое исполнение ордеров (OCO)

**Стандарт логов:** каждое событие содержит: timestamp, level, symbol, action, price, reason, side.
Два вывода: консоль (INFO) + файл logs/ (DEBUG). Ротация по размеру.

**Результат:** Бот подключается к OKX, открывает/закрывает позиции, всё логируется.

---

### Фаза 1.2 — Стратегия
- [ ] Один сигнал входа (простой, проверяемый)
- [ ] OCO на бирже (TP + SL)
- [ ] Реверсальный выход (reversal_detected — WR 75% в старом проекте)
- [ ] Минимальные фильтры: ADX + сила сигнала

**Результат:** Бот торгует, есть первая статистика.

---

### Фаза 1.3 — Тест и калибровка
- [ ] Запуск на демо 1 неделя

- [ ] Одно изменение → тест → повтор
- [ ] Достигнуть WR > 60%

**Результат:** Стабильная стратегия с подтверждёнными метриками.

---

### Фаза 1.4 — Стабилизация

**Результат:** Готово для перехода на реальный счёт.
