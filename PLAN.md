# PLAN - Trading Bot V2

## Текущий этап: ЭТАП S1 - Concierge Analyzer MVP

**Что строим сейчас:** не автоторгового бота, а показываемый анализатор графиков с оператором в контуре.

**Почему:**
- `Strategy E` закрыта и заархивирована в [docs/strategy_e_postmortem.md](c:/Users/krivo/trading-bot-v2/docs/strategy_e_postmortem.md)
- спрос проявился не на бот, а на понятный разбор графика
- analyzer-first даёт шанс быстрее показать ценность и получить первые деньги

**Критерий перехода к следующему этапу:**
- анализатор стабильно работает end-to-end
- output можно показывать без стыда
- есть 5-10 демонстрационных кейсов
- есть первые реальные пользователи или готовность платить

## Архитектурное видение — обсуждено 16.03.2026

### Куда движемся (не сейчас, но понятно направление)

**Концепция: скрипт = данные, LLM = оркестратор**

```
Скрипт (данные)              LLM (решения)
────────────────────         ──────────────────────────
Свечи с OKX           →      Видит: рынок + открытые
Индикаторы            →      позиции + баланс + историю
Открытые позиции OKX  →      анализов
Баланс счёта          →
                             Решает: войти / ждать /
                      ←      отменить / закрыть
Исполняет ордер (лимитка)
```

Ручная торговля остаётся как дополнительная опция, не основной флоу.

---

### 5 проблем которые нужно решить перед автоматизацией

**1. Несоответствие LLM ↔ бот**
- Чарт говорит "НАБЛЮДАЕМ", LLM пишет "вот точка входа"
- Повторный анализ — LLM пишет то же самое как впервые
- "Актуально до X" — а время уже прошло
- Решение: передавать LLM `bot_decision` + `reason` явно

**2. Автоматизация не видит открытые позиции**
- Перед анализом → проверить OKX → есть позиция по паре → пропустить
- Когда позиция закрылась → возобновить анализ

**3. Нет флагов на анализ (статистика)**
- Лог: `analysis_id → signal → position_opened → outcome (TP1/TP2/SL/expired)`
- Без этого нельзя оценить точность системы
- Цель: за 2-3 дня автономной работы накопить статистику

**4. Лимитки вместо рыночных**
- LLM даёт зону входа, TP1, TP2, SL → это лимитные ордера на OKX
- Если цена ушла из зоны → ордер отменяется при следующем анализе

**5. Safety-слой (НЕ отдавать LLM)**
- Макс. размер позиции
- Макс. одновременных позиций
- Дневной лимит потерь
- Эти правила hardcoded в скрипте всегда

## Правила этапов

- Не возвращаться к `Strategy E` и её вариациям без явного нового research
