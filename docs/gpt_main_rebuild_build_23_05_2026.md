Фейд/grind/drift — **НЕ строим** (эджа нет: grind = look-ahead мираж, drift = деньги ~0). Каркас архитектуры
ставим, но населяем одним жильцом.

**Честная оговорка (зашить в сознание):** памп (та же импульс-семья) на форварде день 1 = **net −11.5%, n=8**.
Значит новый импульс-движок строим как **paper для ПРОВЕРКИ форвардом, НЕ как готовые деньги.** Не подгонять.

### Шаг 2 — Импульс-анализатор + мини-оркестратор (отдельный paper-процесс)
- Анализатор: ранний тик-вход (триггер как в пампе) + выход `scaled_tp(impulse_body)` / структурный ride,

- Мини-оркестратор: «тупой исполнитель» — принимает контракт, **paper**-ведёт (BE/trail по контракту),
  закрывает, пишет training-grade записи (как памп). Соблюдает 3 инварианта (фичи раз наверху / один хозяин
  решения / одна пара→один анализатор, лок до закрытия).
