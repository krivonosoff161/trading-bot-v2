## Движок (рывок, paper) — замороженный research-конфиг
- **Детект импульса:** тело 1m-свечи ≥ `2×` среднего за 4 свечи + `vol_ratio ≥ 2.0`; **тиковый триггер:
  первый тик, прошедший `1.0%` от старта за `≤10с`.** Tick-only, без candle-подмены.
- **Пары:** волатильные альты (BSB/EDEN/RLS/CHZ/SPACE/NOT/TURBO/BOME). Параметры — конфиг-словарём.
- **Вход:** по рынку на тике (в лог — реалистичная цена + slippage). **Стоп структурный** (за экстремумом
  импульсной свечи + буфер).
- **Выход:** структурный ride (`structure_k2`/`k3` — держим пока свеча не закроется за прошлым swing-уровнем).
- **Обе стороны** (long/short).
- Базовый circuit breaker / лимиты (paper): max одновременных позиций, cooldown по паре.

## 🎯 ПРАВИЛЬНЫЕ ЗАПИСИ (training-grade — ПЕРВОКЛАССНОЕ требование, НЕ забыть)
Каждый сигнал → **полная структурированная запись, сразу пригодная для будущего обучения** (не сырой мусор):
- `signal_id, ts(UTC), symbol, side, vol_tier`
- **контекст входа:** impulse_body_pct, vol_ratio, trigger_window_sec, entry_lag_pct, adx_1h, price, base_distance
- **исход:** outcome (`ride_exit`/`sl`/`time`), net_pct, mfe_pct, mae_pct, capture_pct, hold_min
- **`valid` флаг** — контроль качества (как `flag_invalid_signals.py`: битые/вырожденные уровни → invalid)
- **формат:** чистый jsonl, совместимый со схемой обучающей БД (`TrainingRecord`, см. BACKLOG G.0.4).
- Отдельный лог сигналов и исходов, единый `signal_id` связывает их.
Цель: через 2-3 недели paper у нас **чистый размеченный датасет** для подтверждения edge И для обучения.
