## Изменение 1 — Начальный стоп за импульс

- long: стоп = `low` импульсной свечи − буфер; short: `high` + буфер.
- Тестировать буфер ∈ `{0, 0.1, 0.2}%`.
- Цель: первый шум/тень не выбивает (см. case 13).

## Изменение 2 — Выход по слому структуры (НЕ тугой трейл)

Заменить «50% тени» на структурный выход. Тестировать ДВА режима и сравнить с раунд-1 трейлом:

**(A) Слом ступеньки (твоя «лесенка» как выход):**
- держим структурный уровень = минимальный `low` последних `k` завершённых баров (для long);
  для short — максимальный `high`.
- выход когда свеча **ЗАКРЫЛАСЬ** за этим уровнем (long: close < уровень; short: close > уровень).
- закрытие, не прокол тенью — это и есть «не выбивать шумом».
- тестировать `k ∈ {1, 2, 3}`.

**(B) Giveback-трейл (отдача от пика):**
- выход если цена откатила на `X%` от максимального достигнутого хода (MFE) сделки.
- тестировать `X ∈ {30, 40, 50}%`.
- даёт хвосту бежать, режет только на крупном развороте.

Оба — без фикс TP (трейдер тащил без TP). Опционально добавить гибрид: снять 30-50% на `+1.0%`,
остаток вести по структуре.
