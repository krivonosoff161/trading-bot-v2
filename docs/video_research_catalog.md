# Видео-ресёрч из инфополя — реестр

Журнал всех видео, прогнанных через `scripts/grab_video.py`. **Единый источник правды** по тому,
что уже разобрано и какой вердикт. Ключ = **shortcode** (номера папок `темаN` могут
переиспользоваться после ретраев/чисток — shortcode стабилен). Медиа лежит в
`docs/инста трасткбрикция/темаN/` (в .gitignore, в репо не коммитится).

**Правила (чтобы агенты не путались):**
- Перед скачиванием нового ролика — проверить shortcode здесь (не дубль ли).
- Перед предложением идеи из видео — проверить статус (не отклонено ли уже).
- Actionable → промоут в `BACKLOG.md`; здесь только статус + указатель, без дублирования содержания.

## Тулчейн / как это качается (честно)

- **reels/видео** — `scripts/grab_video.py <url ...>` или `--from-file urls.txt` → анонимно в `темаN/`
  + транскрипт (faster-whisper) + кадры. Нюанс: части reels нужен `--ffmpeg-location` (нет склеенного
  формата → мёрдж аудио+видео; у движка ffmpeg есть через imageio-ffmpeg).
- **массовый разбор из инсты** — `scripts/parse_ig_export.py <export_dir> [--thread имя] [--out urls.txt]`:
  берёт официальный IG-экспорт сообщений (Download Your Information → Messages → JSON), ранжирует треды
  по числу пересланных постов и вытаскивает все ссылки на reels/посты.
- **картиночные карусели** (`/p/`) — нужен ЛОГИН (картинки за стеной):
  1. браузер: расширение J2TEAM Cookies / Cookie-Editor → «Export as file» (пароль ПУСТОЙ) → JSON.
  2. `scripts/cookies_json_to_netscape.py <export.json> cookies.txt` → Netscape-формат.
  3. `scripts/grab_carousel.py --cookies cookies.txt <url ...>` (или `--from-file`) → gallery-dl
     качает в `_carousels/<shortcode>/`.

**Ограничения честно:**
- IG троттлит быстрые серии запросов (видели в батчах) → бывают FAIL, лечится ретраем + `--sleep-request`.
- cookie = **живой токен сессии**: лежит в gitignore-папке, обращаться как с паролём, протухает за недели → пере-экспорт.
- личку (DM) качалки напрямую не читают — только через официальный экспорт IG (приватный API = риск бана, не используем).
