# GPT Research — Main Screener: late entry by regime + per-regime style (21.05.2026)

## Контекст (зачем)

Майн-скринер (`ws_main_screener.py`) даёт направленно верные сигналы — **WR 75%** по решённым
(7 дней: 18 TP / 6 SL). НО **41% сигналов выходят по TIME** (17 из 41) — то есть не доходят ни до
TP, ни до SL, а истекают по времени.

Гипотеза трейдера (по визуальному просмотру снапшотов): **вход происходит слишком поздно** — к
моменту входа движение уже в основном случилось, поэтому цена дрейфует вбок → TIME-выход.

Задача — проверить это в цифрах и на картинках, **по каждому режиму рынка отдельно**, и предложить
правильный стиль входа под каждый режим. Метод тот же, что сработал с continuation (графики + честный
замер + свобода гипотез у GPT).

## Задача 1 — Замер «опоздания» входа

Для каждого VALID сигнала посчитать, насколько поздно вошли:
- **`move_consumed_pct`** — какой % расстояния entry→TP1 уже был пройден ценой к моменту входа
  (т.е. насколько движение уже состоялось до входа). Высокий % = поздний вход.
- **`bars_since_trigger`** — сколько баров прошло от начала фактического движения (импульсной/трендовой
  свечи) до входа.
- **`mfe_after_entry` vs `mae_after_entry`** — осталось ли движение после входа, или ход уже исчерпан.
- Связь с исходом: верно ли, что **TIME-выходы = высокий `move_consumed_pct`** (поздний вход)?

Свести таблицей **по режиму × стилю** (DRIFT/TRENDING/RANGING × FAST/SWING).

## Задача 2 — Картинки (для глазной проверки трейдером)

Отрисовать **по 5-8 сигналов на каждый режим** (особенно TIME-выходы — это и есть поздние входы):
свечи + точка входа бота + где реально было движение (trigger→пик) + SL/TP уровни + исход.
Сохранить PNG в `output/`. Цель — трейдер глазами подтвердит «да, поздно» или «нет, норм».
matplotlib (reference: `src/strategy/chart_renderer.py`).

## Задача 3 — Альтернативный вход, по каждому режиму

На ТЕХ ЖЕ сигналах прогнать варианты входа и сравнить (net после комиссии, доля TIME, WR):
- **immediate** — как сейчас (вход на закрытии триггер-свечи).
- **pullback** — дождаться отката к EMA20/уровню после триггера, войти там (лучше цена, меньше опоздание).
- **breakout/confirmation** — вход на подтверждении продолжения.

**Важно:** для каждого режима ответ может быть РАЗНЫЙ (в тренде — один стиль, в боковике/дрейфе — другой).
Не искать один стиль на всё.
