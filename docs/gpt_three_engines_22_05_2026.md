# GPT — ТРИ движка, каждый со своей логикой и своими метриками (22.05.2026)

## Зачем (главное)

Мы спаяли 3 системы в один тест (общий импульс-детектор) — и тест показал: **внутри 3 РАЗНЫХ зверя,
а одна импульс-линейка (вход на свече + тесный R-TP) их корёжит.** Поэтому майн/тренд и диапазон
выглядели как «схватили огрызок».

Развести обратно: **тренд / импульс / диапазон — каждому СВОЯ логика входа-выхода И СВОЯ таблица
метрик** (метрики у них РАЗНЫЕ — нельзя мерить тренд линейкой пампа). Маршрутизация — по исправленной
классификации режима (Phase B Часть А).

Примеры из разбора трейдера (для понимания, что есть что):
- **Тренд:** case 3д — шорт устойчиво прёт с 02:00 (надо ПОЙМАТЬ и ЕХАТЬ, а не брать одну свечу).
- **Диапазон:** case 4д — чистые осцилляции long/short между границами (это BB FADE).
- **Импульс:** late-кейсы EDEN/HMSTR — резкий рывок (это памп, тик-уровень).

## ДВИЖОК 1 — ТРЕНД (майн, ИНТЕР-ДЕЙ)
**Где:** TRENDING-регим, УСТОЙЧИВОЕ направленное движение (НЕ одна импульсная свеча). Пример: 3д.
**Условия (GPT пропиши явно):** подтверждённый тренд (EMA-выравнивание + ADX + slope по старшим ТФ),
направление структурно по тренду.
**Вход:** продолжение тренда — откат к EMA20/структуре ВНУТРИ тренда (а не одиночный импульс на close).
**Выход:** ЕДЕМ — структурный трейл по свингам / широкий ATR-трейл / выход на СЛОМЕ тренда. **НЕ тесный R-TP.**
Холд интер-дей (часы).
**Своя таблица метрик:** WR, средний R пойман, **% устойчивого хода пойман**, hold (часы), доля выходов
по слому тренда, net после fee. Бенчмарк — продовый DRIFT×FAST (WR ~90%, он и есть рабочий тренд-движок).

## ДВИЖОК 2 — ИМПУЛЬС (памп)
**Где:** резкие импульсы, ВОЛАТИЛЬНЫЕ альты (high-vol tier). Пример: EDEN/HMSTR late-кейсы.
**Условия:** импульсная свеча (тело ≥ N× среднего) + объём; **тиковый триггер** «X% за Y сек от старта».
**Вход:** РАННИЙ, на тиках (tape), НЕ на 15m-close (вход у старта импульса, не у вершины). Шорт-сторона
была сильнее (проверить).
**Выход:** структурный ride / giveback (как `continuation_model_v3`).
**Своя таблица метрик:** capture импульсного MFE, **entry lag** (% хода пройден до входа), MAE-до-MFE,
hold (минуты), net после fee.

## ДВИЖОК 3 — ФЕЙД (BB, диапазон)
**Где:** RANGING-регим (исправленный: низкий ADX, BB-коридор, узкий дневной диапазон) — осцилляции. Пример: 4д.
**Условия активации (GPT пропиши явно, с примером 4д):** цена у ГРАНИЦЫ BB + ADX низкий + BB-коридор
(не расширяется) + НЕ пробой. **Залетает с двух сторон:** шорт у верхней границы / лонг у нижней.
**Вход:** у границы → фейд К СРЕДНЕЙ.
**Выход:** средняя BB (mean-reversion) / противоположная граница. Холд короткий.
**Своя таблица метрик:** fade WR, R до средней, касаний границы/день, hold, net после fee.
