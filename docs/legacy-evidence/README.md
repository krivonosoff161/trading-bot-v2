# Legacy Evidence

Status: **REFERENCE**. These are sanitized retrospective summaries of early
paper/research work. They explain decisions that shaped the current project;
they are not current strategy specifications, validation results, or trading
instructions.

## What This Section Is

The project went through exploratory stages before the current public
paper/research boundaries and independent-validation bridge existed. This
section records a small number of useful negative and inconclusive outcomes:

- an early backtest snapshot that exposed measurement limitations;
- a multi-timeframe idea that produced too few usable candidates;
- a reversal idea whose apparent gross behavior did not survive cost-aware
  evaluation;
- an impulse idea that did not survive forward paper observation.

The value of these records is methodological: an early result is a hypothesis,
not a product claim. Each page describes what was learned and why the current
workbench uses bounded paper observation and independent validation.

## What Is Deliberately Excluded

This section does not publish raw data, per-trade paths, pair rankings,
parameter sweeps, model conversations, source scripts, charts, journals, or
runtime output. Those artifacts are local-only under the project storage
policy.
