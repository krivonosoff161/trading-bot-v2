# Официальный OKX MCP подключён + sentiment-зонд (2026-05-27)

Продолжение охоты после 12 каналов (см. `telegram_channels_synthesis_2026-05-27.md`,
`branch_ab_results_2026-05-27.md`). Трейдер указал на **официальный OKX MCP** — подключили для данных.

## Что подключено

**OKX Agent Trade Kit** (`@okx_ai/okx-trade-mcp`, github.com/okx/agent-trade-kit) — официальный MCP-сервер OKX.
- Установлен глобально (`npm i -g`), прописан в `.claude/settings.json` как `okx-official` в режиме
  **`--modules market,news --read-only`** (торговых тулзов не существует → money-guard цел).
- Аутентификация: трейдер сам выполнил `okx config init` (ключ в `~/.okx/config.toml`, ВНЕ репо, Claude ключ не видит).
- В чат-интерфейс Claude Code тулзы `okx-official` не пробросились — дёргаем сервер из скриптов по JSON-RPC
  (`probe_okx_mcp.py`, `okx_mcp_call.py`). Для бота это неважно (бот ходит в OKX напрямую).

**Доступность модулей (v1.3.5):**
- 🟢 `market` — БЕЗ ключа: candles+история, funding, **open interest + oi_history**, market_filter, индикаторы, pair_spread.
- 🟢 `news` — после auth: news_get_latest/by_coin/search, **news_get_coin_sentiment** (снимок + trend), sentiment_ranking, **economic_calendar** (CPI/NFP/FOMC).
- (вопреки маркетинг-странице, news БЕЗ ключа НЕ работает — `requires_auth`.)

## Глубина данных — ключевое ограничение

`news_get_coin_sentiment` отдаёт `trend`-массив, но **shallow**: ~30 точек макс (trendPoints=60 → «limit error»).
При `period=1h` это ~30 часов, при `24h` — ~30 дней. **Глубокого исторического OOS-бэктеста нет** — это near-real-time
инструмент, не архив. Та же стена, что с rubik-позиционированием (~2 дня). News-статьи — тоже свежие.

## Дешёвый sentiment-зонд (`sentiment_edge_peek.py`)

На тех ~30 днях, что есть: IC(net_sentiment[t] = bull−bear ratio → forward 1d ход), 15 монет, дневки из `_okxhist`.

**Предсказание (до запуска):** IC≈0 или слабо-ОТРИЦАТЕЛЬНЫЙ (контртренд).
**Результат — ПРОТИВ предсказания:** `IC=+0.095, t=+1.9`, спред верх/низ квартиль булиша **+0.62% vs −0.26% (=+0.88%)**.
Слабо-ПОЛОЖИТЕЛЬНО (моментум-подобно: булиш-настроение → чуть выше ход вперёд).

**Дисциплина — t завышен, это намёк, не значимость:**
- n=420, НО 15 монет × ~29 дней, сильное перекрытие + кросс-корреляция монет → эффективно независимых ≈ **29 дней**.
  Аналитический t=1.9 **оптимистичен** (ловушка перекрытия, как в аутопсии майна). Реально — на грани шума.
- Один режим (~месяц), без OOS. Может быть период-специфично.

## Вывод и решение

Это **первое за всю охоту (A/B/SFP/ротация), что не вернулось явным минусом** — слабый положительный намёк.
НЕ «эдж найден». Глубокого бэктеста нет (данные shallow). Правильный ход — **ФОРВАРД-СБОР**:
лёгкий ежедневный сборщик (read-only: net_sentiment + mentionCnt + цена по корзине → CSV), копит **чистый
неперекрытый** дневной ряд 3-4 недели → затем честный OOS-тест sentiment→ход. Это тот самый «накопить данные,
которых нет в истории» = реальный разблокировщик, названный ранее. Сборщик НЕ построен (ждёт GO трейдера).
