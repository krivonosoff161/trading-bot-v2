## Executive Summary

Система демонстрирует **фундаментальное противоречие**: свинг-стратегия требует постоянного мониторинга, но оператор доступен только **2-3 часа вечером**.

**Цифры:**
- 20 часов без присмотра vs 2-3 часа доступности
- -78.30 USDT убытки на unattended-позициях = **251%** от итогового положительного результата
- Без двух убыточных сделок результат дня: **+109.38 USDT** вместо +31.08
- Лучшая сделка: XRP range trade **+92.70 USDT за 3 минуты** — выполнена вне системной логики

**Ключевой инсайт:** XRP был ручным range trade без аналитика. Направление развития — краткосрочные range-сетапы с полным контролем в вечернем окне, не протяжённые свинг-позиции с ночной экспозицией.

## 1. Диагностика текущей системы

### 1.1 Фундаментальное противоречие

Оба крупных убытка произошли по идентичному сценарию: статичный SL в зоне ликвидности → мишень для "свипа" → краткосрочный пробой → немедленный возврат цены. При наличии оператора такое движение идентифицировалось бы как ложный пробой. В отсутствие — механически зафиксировался убыток в точке максимального неблагоприятного движения.

### 1.2 Структурные дефекты UX
Фрагментированный процесс: ручной выбор пары → ожидание LLM → интерпретация Telegram → переключение на OKX → ручной ввод ордеров. Каждый переход — точка трения, задержки и потенциальной ошибки.

Несоответствие горизонтов: LLM генерирует TP 2-5% (часы-дни), оператор в 4 из 5 сделок выходит вручную по 1m сигналам. Попытка принудить к удержанию противоречит наблюдаемым паттернам успеха.

### 1.3 Индикаторные ограничения
- **ADX ≥ 20** — пропускает слабые тренды в переходных фазах (значения 20-25 = опасная зона)
- **EMA-откат без осциллятора** — ловушка без контекста перекупленности
- **Фиксированный ATR** — не адаптируется к режиму, SL в уязвимых зонах

## 2. Сравнительный анализ стратегий

| Подход | ТФ | TP | Горизонт | Вердикт |
|--------|----|----|----------|---------|
| Скальп | 1m/5m | 0.3-1% | минуты | ❌ Несовместим — задержка LLM критична, требует co-location |
| Свинг | 1H/4H | 2-5% | часы-дни | ⚠️ Только с полной автоматизацией защиты |
| **Гибрид** | **4H→1H→5m** | **гибко** | **вечер→утро** | **✅ Рекомендуется** |

### Рекомендуемый подход: "Вечерний range + тренд-фильтр"

**Приоритет 1 — Range trades:**
- Полный контроль в вечернем окне
- Предсказуемый R:R при чётких границах
- Нет ночной экспозиции
- Критерии: BandWidth(4H) < 12% стабильно 5+ свечей

**Приоритет 2 — Trend swings (макс 20-30% портфеля):**
- Только при ADX(4H) > 25
- Только с автоматизированным трейлинг-стопом
- Обязательный утренний контроль

**Запретная зона — абсолютное правило:**
> Любые позиции без автоматизированного механизма выхода — исключены

## 3. Оптимизация индикаторов

### Убрать / заменить
| Что | Проблема | Замена |
|-----|----------|--------|
| EMA50(15m) как SL | Частые свипы, близко к цене | Структурные уровни (swing low/high 4H) + ATR буфер |
| ADX ≥ 20 | Слишком мало, пропускает слабые тренды | ≥ 25 + ADX(4H) > ADX(1H) |
| Фиксированный ATR | Не адаптируется к режиму | ATR(4H) для свингов, ATR(1H) для range |

### Добавить
| Индикатор | ТФ | Назначение |
|-----------|-----|------------|
| RSI(14) | 1H, 15m | Тренд: вход 40-70, Range: вход <30/>70 |
| Bollinger Bands(20, 2.5) | 1H | Режим рынка: squeeze/expansion |
| BandWidth | 4H | Range-кандидаты: < 10% стабильно 5+ свечей |
| Stochastic(14,3,3) | 5m | Тайминг входа в range: %K/%D в зоне <20/>80 |
| ADX(4H) с +DI/−DI | 4H | +DI > −DI для подтверждения long |

### Объём
Перейти с абсолютного на **относительный**: текущий объём / 20-периодный SMA

## 4. Архитектура SL/TP — "луковица"

### Три уровня защиты

**Ядро — начальный SL:**
- Range: за пределами боковика + 0.5×ATR(4H)
- Trend: за swing low/high на 4H + 1×ATR(4H)

**Средний слой — break-even:**
- Триггер: прибыль ≥ +1.5×ATR(1H)
- Действие: SL → точка входа + 0.15% буфер

**Внешний слой — трейлинг:**
- Активация: движение на +2.5×ATR
- Шаг: 0.5×ATR при новом экстремуме

### Chandelier Exit — ключевой инструмент
```
CE = Highest High(22) − ATR(22) × 3.5
```
- Lookback: 22 часовые свечи (~сутки)
- Мультипликатор: **3.5** (стандарт 3.0, адаптация под крипто)
- Обновление: при закрытии каждой 1H свечи
- Интеграция: условный ордер OKX через API

### Инвалидация
| Тип | Триггер | Действие |
|-----|---------|----------|
| Структурная | 1H свеча против тренда за 2×ATR | Выход по рынку |
| Временная | 24ч (range) / 72ч (trend) без прогресса | Принудительное закрытие |
| Индикаторная | ADX(4H) < 20 | Выход или агрессивный трейлинг |

## 5. Роль LLM в пайплайне

### Что делает LLM
- Классификация режима рынка (trend/range/transition)
- Оценка "чистоты" сетапа
- Выявление скрытых рисков
- Генерация "сценария развития"
- **Периодический рескоринг каждые 4 часа** (00:00, 04:00, 08:00, 12:00, 16:00, 20:00 UTC)

### Что делает код (100% детерминированно)
- Расчёт всех индикаторов
- Проверка фильтров входа
- Размещение ордеров через API
- Обновление трейлинг-стопов
- Принудительный выход по инвалидации

### Критическое правило
> **LLM не генерирует числовые уровни SL/TP.** Код считает уровни сам на основе рекомендации LLM (тип стратегии, confidence) и текущих данных.

### Триггеры ручного вмешательства (Telegram-алерты)
- Структурное нарушение сценария
- Неожиданная волатильность
- BTC движение >3% за час при открытой альт-позиции

## 7. Альткоины — range trading

### Критерии идеального range-альта
- BandWidth(4H) < 12% стабильно 5+ свечей
- Минимум 3 чётких касания верхней и нижней границы BB
- RSI(1H) колеблется 30-70 без экстремумов
- Высокая ликвидность (объём достаточен для исполнения)

### Автоматический скринер range-кандидатов
Алгоритм: для каждой пары из списка → расчёт BandWidth(4H) → фильтр < 12% → подтверждение BB касаний → сортировка по качеству

### BTC vs. альты
- BTC: более предсказуемая структура, меньше слипейдж, меньше % ходы
- Альты: более широкие диапазоны, выше R:R потенциал, выше риск манипуляции

## 9. Конкретные параметры для имплементации

### Свинг-фильтр (модифицированный)
```
ADX(4H) > 25
AND ADX(1H) > 20
AND +DI > −DI на обоих ТФ
AND относительный объём > 1.5 × SMA(20)
AND RSI(1H) между 40 и 70

Вход: откат к EMA20(15m) при RSI(15m) < 50
```

### Range-фильтр (приоритетный)
```
BandWidth(4H) < 12% стабильно 5+ свечей
AND минимум 3 касания верхней и нижней границы BB
AND RSI(1H) колеблется 30-70 без экстремумов

Вход: лимитный ордер у границы
      + Stochastic(5m): %K пересекает %D в зоне <20 (long)
```

### Chandelier Exit
```python
lookback = 22          # часовые свечи
multiplier = 3.5       # крипто-адаптация
ce_long = max(highs[-lookback:]) - atr(22) * multiplier
# Обновление: при закрытии каждой 1H свечи
```

### Риск-менеджмент
- Риск на сделку: 2-4% от депозита
- Range trade: макс 80% портфеля
- Trend swing: макс 20-30% портфеля
- Позиций одновременно: не более 3
