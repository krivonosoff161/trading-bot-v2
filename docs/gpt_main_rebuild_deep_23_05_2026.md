## ЗАДАЧИ (приоритет P0 → P2). Везде: NET после fee 0.20%, обе стороны, n≥20, держится рано/поздно.

### P0-1. Вывести TP/SL-формулы под КАЖДЫЙ режим ИЗ ДАННЫХ (не гипотезы — замеры)
FAST/SWING как ось убрана → геометрия выводится на ХАРАКТЕР режима. Для TRENDING-импульс / DRIFT / RANGING:
1. Построй **распределение реального хода** после правильной точки входа: MFE и MAE по перцентилям (p25/50/75/90), по сторонам, по vol-tier.
2. Из распределения **выведи формулу**: SL = f(структура/ATR какого ТФ — проверь 15m vs 1h vs swing), TP = f(перцентиль MFE / тело импульса / структурный уровень), целевое R:R.
3. **Прогони выведенную формулу против текущей** (RR1 0.48, кэп 1.2·ATR_1h) на наших сигналах → дельта NET по ячейкам.
Выход: таблица «текущая vs выведенная геометрия», формула словами+кодом, к каким перцентилям привязана.

### P0-2. Подтвердить/завалить GO по TRENDING_IMPULSE на РЕАЛЬНЫХ тиках + фальсификация
В моём replay вход — прокси (open/mid/close на 15m). У тебя есть тики → **сделай настоящий ранний тик-вход** (триггер «X% за Y сек», как в импульс-движке) и перемерь NET. Затем **фальсификация GO** (mid +0.48%, n=55):
- out-of-sample: раздели окно (04-09 vs 09-14) — держится на обоих?
- pair-split: выкинь топ-вкладчика — выживает?
- permutation/shuffle сторон — net не должен оставаться + на шумных метках.
- обе стороны и рано/поздно — стабильны?
Вердикт прямой: GO выживает на реальном входе или это артефакт прокси/окна/одной пары.

### P1-2. RANGING — фейд-модель (ранний вход вреден, значит другое лекарство)
