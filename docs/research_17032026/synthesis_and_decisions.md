## Новая концепция продукта (обсуждено 17.03.2026)

**Ключевое решение:** LLM = мозг системы, Python = поставщик данных

```
Python считает индикаторы → snapshot.json
→ LLM читает данные + жёсткие правила в промпте
→ LLM решает: LONG / SHORT / NO_TRADE
→ LLM генерирует сигнал + структурированный текст
```

**Преимущества:**
- Стратегию меняешь через промпт, не через код
- LLM гибче чем 5 жёстких if/else (Strategy E провалилась)
- Для сигнального сервиса идеально

**Главный риск:** LLM без жёстких правил будет вечно писать "ждём"

**Решение — дерево решений в промпте:**
```
Шаг 1: ADX(1H) > 18 И EMA21 > EMA55?
→ НЕТ = NO_TRADE. Стоп.

Шаг 2: Цена у EMA21 на 15m?
→ НЕТ = ЖДЁМ. Стоп.

Шаг 3: RSI(15m) > 52 (лонг) или < 48 (шорт)?
→ НЕТ = ЖДЁМ. Стоп.

Шаг 4: Volume >= 1.5x SMA20?
→ НЕТ = ЖДЁМ. Стоп.

Все 4 ДА = LONG/SHORT обязательно.
```
